# draft-only-mail-triage

An hourly Python job for Scaleway Serverless Jobs (fr-par) that reads one Gmail label or
one Outlook folder, asks an OpenAI-compatible model (Scaleway Generative APIs, Qwen) for
a reply, saves it as a **draft in the sender's thread**, and adds up to three proposed
tasks to **one** Todoist project. Its only write to the mailbox is that draft; sending is
left to a person.

This is a **reference implementation**, with tests that try to break it and an evidence
register generated by those tests. It is technical evidence for an AI management system review,
not a certification of anything.

**Status.** Nothing is deployed. No real mailbox, no OAuth consent, no Scaleway account
was used. Gmail, Microsoft Graph and Todoist are replaced by in-process fakes that follow
the public request and response shapes and sit behind the real allowlist and the real
client code. The example drafts were generated by a local Qwen (`qwen3:8b`, 8.2B
parameters, Q4_K_M, via Ollama on a Mac); the same client points at Scaleway Generative
APIs in fr-par in production.

## Layout

| Path | What it is |
|---|---|
| `src/triage/transport.py` | The only network module. `AllowlistTransport` refuses any request off the list before emission. |
| `src/triage/job.py` | One hourly pass: claim, ledger, reconcile, model, checks, draft, tasks. |
| `src/triage/checks.py` | Language detection, output schema, refusals (added figures, dates, names, echo, wrong language). |
| `src/triage/ledger.py` | Durable state without content: file backend and S3 backend (Object Storage fr-par). |
| `src/triage/providers/` | Gmail (`readonly` + `compose`) and Graph (`Mail.ReadWrite`, no `Mail.Send`). |
| `src/triage_fakes/` | Fakes of Gmail, Graph, Todoist, the model and S3. Test and demo infrastructure only. |
| `corpus/` | Synthetic `.eml` messages (`example.org`), no real person. |
| `examples/qwen3-8b/` | Prompts and raw outputs of the local Qwen, one file per email. |
| `tests/` | The control tests. They never depend on a model. |
| `evidence/` | `requirements.json` (register rows) and `evidence.json` (written by pytest). |
| `terraform/` | Job definition, hourly trigger, secrets by reference, registry, ledger bucket, two identities. |
| `.github/workflows/monthly-rebuild.yml` | Monthly rebuild from scratch, audit, SBOM, corpus run, push by digest when secrets exist. |
| `SECURITY.md`, `RUNBOOK.md`, `REVOCATION.md`, `docs/adr/0001-idempotence.md` | The hand-over. |

## Commands

```bash
python3.12 -m venv .venv && .venv/bin/pip install -e '.[dev]'

# All control tests, and the evidence register they produce (about 3 minutes: the
# concurrency test races two runs 200 times)
.venv/bin/python -m pytest -q --evidence evidence/evidence.json

# Every test is linked to a register row except three: the two checks on the register
# itself (tests/test_register.py) and the refusal of a partial configuration.

# Does the suite bite? Four dangerous mutants, each must turn the suite red
.venv/bin/python tools/mutation_check.py

# Replay the synthetic corpus through the fakes with the recorded Qwen outputs
.venv/bin/python -m triage demo
.venv/bin/python -m triage demo --provider graph

# Record the "one hour, traced" scenario (draft, injected Todoist failure, resume)
.venv/bin/python -m triage trace out/trace.json

# Production entry point: refuses to start until the configuration is complete
.venv/bin/python -m triage check-config
.venv/bin/python -m triage run

# Regenerate the examples with a local model (needs Ollama serving qwen3:8b)
.venv/bin/python tools/generate_examples.py --base-url http://127.0.0.1:11535/v1 --model qwen3:8b
```

`terraform fmt -check` and `terraform validate` run inside the test suite when
`terraform` is on the PATH (they do in CI). That is "configuration validated locally",
not a deployment.

## Configuration

All identifiers come from the environment, never from the model:
`MAIL_PROVIDER` (`gmail` or `graph`), `GMAIL_LABEL_ID` or `GRAPH_FOLDER_ID`,
`TODOIST_PROJECT_ID`, `LLM_BASE_URL` (default `https://api.scaleway.ai/v1`),
`LLM_MODEL` (default `qwen3-235b-a22b-instruct-2507`), `LEDGER_BACKEND` (`file` or `s3`)
and `LEDGER_PATH` or `LEDGER_BUCKET`. Secrets (refresh tokens, Todoist token, model key,
ledger keys) are Secret Manager references in `terraform/main.tf`.
